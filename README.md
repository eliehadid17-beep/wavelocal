# WaveLocal

A local-first music streaming app in the spirit of Anghami / YouTube Music — but it only
plays **your own files and bundled royalty-free demo tracks**, so there are no copyright
issues and nothing is streamed from third parties.

## Features

- **Library** — upload your own audio (mp3, wav, ogg, m4a, flac, up to 30 MB each)
  with title / artist / album metadata and optional cover art
- **Player** — persistent bottom player, queue, shuffle, repeat (off/all/one), seek,
  volume, keyboard shortcuts, OS media keys (Media Session API)
- **Playlists** — create, rename, delete, add/remove tracks, three seeded demo mixes
- **Liked Songs** — one-tap favorites
- **Search** — instant search across titles, artists and albums
- **Demo content** — six fully synthesized, royalty-free tracks with generated cover art
- **PWA** — installable on desktop and mobile, offline app shell
- **Responsive** — desktop sidebar layout and a mobile layout with bottom nav,
  mini-player and a full-screen now-playing view

## Tech stack

React 19 + TypeScript + Vite + Tailwind + shadcn/ui on the front;
Hono + tRPC + Drizzle ORM (MySQL) on the back. Files are stored in object storage
when deployed on the Kimi platform, or on local disk (`./uploads`) when self-hosted.

## Run locally

Requirements: Node.js 20+, a MySQL 8 database (or Docker), and optionally
Python 3 + ffmpeg if you want to regenerate the demo tracks.

```bash
# 1. install dependencies
npm install

# 2. configure environment
cp .env.example .env
# edit .env and set DATABASE_URL, e.g.:
#   DATABASE_URL=mysql://wavelocal:wavelocal@localhost:3306/wavelocal

# (optional) start a MySQL container for development:
docker compose up -d

# 3. create the tables
npm run db:push

# 4. seed the demo tracks (generates/serves 6 royalty-free songs + mixes)
npm run seed

# 5. run it
npm run dev        # development, http://localhost:3000
# or
npm run build && npm start   # production, http://localhost:3000
```

Uploaded files are written to `./uploads` and served from `/uploads/*` when no
platform object-storage credentials (`KIMI_*` env vars) are present — which is the
case for any local/self-hosted run. Nothing ever leaves your machine.

## Regenerating the demo music (optional)

The six demo tracks and all cover art are 100% machine-generated by
`scripts/generate-seed-assets.py` (numpy + Pillow + ffmpeg). To regenerate:

```bash
pip install numpy pillow scipy
python3 scripts/generate-seed-assets.py   # writes into seed-assets/
npm run seed                              # re-seed (skips if tracks exist)
```

The generated audio and artwork are released into the public domain (CC0) —
use them however you like.

## Project layout

```
api/            Hono server, tRPC routers, storage abstraction
contracts/      shared types (frontend ↔ backend)
db/             Drizzle schema + seed script
public/         PWA manifest, service worker, icons
scripts/        demo-asset generator
seed-assets/    generated demo audio + covers (input to npm run seed)
src/            React frontend (pages, components, player)
```

## Notes

- This is a **personal, single-user** app: there is no login. If you expose it to
  the public internet, put it behind your own auth/reverse proxy.
- Deployed on Kimi, file storage and the database are provided by the platform;
  exported/self-hosted copies use your own MySQL and local disk instead.
